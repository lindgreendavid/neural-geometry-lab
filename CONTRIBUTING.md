# Contributing

Open an issue before changing a scientific endpoint, source identity, condition construction, or
interpretation. The v1.0 protocol and result register are frozen: never overwrite them. A changed
research design receives a new versioned protocol and result artifact, with the reason documented
before the new analysis is run.

Code changes should include focused tests. Claim changes must cite a primary source or committed
machine-readable result. Run formatting, linting, type checks, tests, the release validator, and the
package build before opening a pull request. Do not commit raw UCI files, credentials, local
environments, caches, or generated temporary output.
