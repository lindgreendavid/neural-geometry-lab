# Security policy

## Supported version

Security fixes are provided for the latest public release.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories. Do not publish credentials,
private data, or exploit details in an issue. The project retrieves only the public UCI archive named
in `data/provenance-v1.0.json`; the fetcher verifies the frozen archive and member checksums before
use. Raw source files are excluded from Git.
